    Start a chat from a ticket

    New chat writes the prompt from the ticket. Tick worktree, start, and the agent moves the ticket to Active. Each folder picks its board: Local, Trello or Jira.

    Linked both ways

    The chat shows its ticket, and the ticket lists its chats. The agent asks before it runs a command, and a ready pull request moves the ticket to Review.

    It suggests what comes next

    Follow-up work the agent spots waits above the composer. Start it in a new worktree, file it as a ticket, or swipe it away.

    Review beside the chat

    The uncommitted changes or the whole branch, file by file.

    A browser and devices you share

    The agent drives a browser and your iOS Simulator or Android emulator while you watch, and you can click and tap along.

    Boards

    Your board, wherever it lives.

    Connect a board to a project folder, and the agent works with it.

    LocalTrelloJira

    Works with

    The agents you already use.

    X Bench drives the Claude Code, Codex and Grok Build CLIs you already have signed in. Sign-in, models and transcripts stay with each agent. One model menu lists them all, and a chat can move to another agent's model and keep going.
