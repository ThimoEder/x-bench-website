# X Bench website

The website of [X Bench](https://github.com/ThimoEder/x-bench), a free, open-source Mac app for Claude Code, Codex and Grok Build. It lives at [xbench.dev](https://xbench.dev).

The site is plain HTML with no build step. GitHub Pages serves it from the root of `main`. To preview it, open `index.html` in a browser, or run `python3 -m http.server` and open http://localhost:8000.
